# BeautyCommerce

Repositorio organizado por capas:

- `backend/`: API ASP.NET, aplicación, dominio, infraestructura y pruebas.
- `frontend/`: aplicación web Vite/React.
- `docs/`: documentación de arquitectura, decisiones y runbooks.
- `tools/`: scripts y utilidades de apoyo.

Puntos de entrada principales:

- Backend: `backend/BeautyCommerce.API/BeautyCommerce.API.slnx`
- Frontend: `frontend/BeautyCommerce.Web/package.json`
